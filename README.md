

# Ryvalx Mobile App

## About Project

Ryvalx is a cricket assessment and learning mobile application.  
The app helps users evaluate their cricket skills through technical, tactical, physical, and mental assessments.

Users can log in using mobile OTP verification, choose their cricket role, and complete assessments based on their skills.

---

# Features

## Authentication
- Mobile number login
- OTP verification
- Resend OTP option
- Edit phone number option

## Welcome Screen
- User greeting screen
- Assessment introduction
- Begin assessment option
- Skip option

## Role Selection

Users can choose:
- Batting
- Bowling
- Wicket Keeping
- All-rounder

Users can also select:
- Batting style
- Bowling style

## Navigation Flow

   ↓
Send Code
   ↓
Verify Code
   ↓
Welcome Screen
   ↓
Begin Assessment
   ↓
Choose Role
   ↓
Next
   ↓
Assessment Screen
   ↓
Submit Assessment

## Detailed User Flow

User opens the application,
User enters mobile number,
User taps Send Code,
OTP verification screen opens,
User enters OTP,
User taps Verify Code,
Welcome screen appears,
User taps Begin Assessment,
User selects cricket role,
User selects batting and bowling style,
User taps Next,
Assessment questions appear,
User rates skills,
User continues assessment
